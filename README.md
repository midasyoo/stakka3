## 게임 소개

**STAKKA 2** 에서 별이 달에 닿은 순간, 그 충격으로 달이 갈라졌다.
틈에서 새어나온 심연이 하늘 전체를 무너뜨리기 시작한다.

이제 별은 여유롭게 쌓아 올라가는 게 아니라 **무너지는 하늘보다 빨리 도망쳐야** 한다.

> 화면 아래서 **붕괴선** 이 바다처럼 출렁이며 계속 차오른다.
> 머뭇거리면 삼켜진다. **PERFECT** 로 쌓아야만 붕괴선을 밀어낼 수 있다.

쌓기 타이밍 + 방해물 회피 + **시간 압박** — 세 겹의 긴장감이 동시에 걸린다.
STAKKA 2를 완전 클리어한 플레이어를 위해 전 구간 난이도를 확실하게 올렸다.

- **붕괴선 추격** — PERFECT로 쌓을수록, 콤보가 쌓일수록 크게 밀어낼 수 있다. 정확도가 곧 생존.
  위험할수록 화면 가장자리가 붉게 물들고, 심장박동 사운드가 점점 빨라진다.
- **10개 레벨 전부 신규 테마** — 잿빛 박쥐떼, 뇌우 전선, 파편 지대, 부유 잔해, 심연의 그림자,
  굶주린 추적자, 분노한 뇌전, 유성 폭풍을 거쳐 마지막 **균열의 문** 에서는 유성과 번개가
  동시에 쏟아지는 보스급 구간으로 마무리된다.
- **레벨 5부터 해저 화산** — 붕괴선 바다 속에서 용암이 솟구친다. 레벨이 오를수록 더 잦고
  격렬해진다. (데미지 없는 순수 演출 — 위기감을 더한다.)
- 죽는 원인이 셋으로 구분된다 — 방해물에 **맞았다** / 잘못 쌓아 **무너졌다** / 붕괴선에 **삼켜졌다**.
- 레벨 클리어마다 체크포인트 저장, 60층(10레벨) 도달 시 균열 너머로 **탈출** 엔딩.

## 게임 방법

### 조작

화면 아무 데나 **탭** (PC: 클릭 / 스페이스바).

### 핵심 규칙

1. 블록이 좌우로 왕복. 탭으로 아래층에 맞춰 쌓는다.
2. 빗나간 만큼 **잘려나간다.**
3. **방해물이 탑 꼭대기를 가로지를 때 쌓으면 → 맞아서 게임오버.** 쌓지 말고 기다려라.
4. 거의 정확히 맞추면 **PERFECT**. 콤보 2부터 블록이 다시 커진다(회복) —
   **그리고 붕괴선이 크게 밀려난다.**
5. HUD의 보라색 **위험도 바** 를 주시하라. 노랑→빨강으로 바뀌며 차오르면 붕괴선이 임박한 것.
6. 각 레벨의 목표 층수(6층)에 도달하면 다음 구역으로. 60층(10레벨) = 균열 너머 탈출.

### 죽으면?

- **체크포인트** 가 켜져 있다 — 현재 레벨의 시작부터 다시 (붕괴선 여유도 새로 생성).
- "처음부터" 버튼으로 1레벨부터 재시작할 수도 있다.
- 최고 도달 레벨은 자동 저장.

## 기술

- Canvas 2D + 자체 아이소메트릭 투영
- 방해물은 **이모지 렌더링** (에셋 0, 기본 폰트)
- 붕괴선은 **화면 좌표 기반 파도** — 월드 공간 평면으로 그리면 이 게임의 등각 투영 특성상
  왜곡이 심해져, "다음 레벨 문턱" 표시선과 같은 방식으로 다시 설계했다
- 마스코트(작은 별)는 캔버스 도형으로 실시간 드로잉 — 위험할수록 겁먹은 표정으로 변화
- Web Audio 실시간 합성 (레벨업/탈출 징글 + 위험 심장박동음 포함)
- iOS 인앱브라우저·노치·주소창 대응

## STAKKA 2와의 차이

| | STAKKA 2 | STAKKA 3 |
|---|---|---|
| 목표 | 달에 도착 | 균열 너머로 **탈출** |
| 신규 메커닉 | 방해물 회피 | **붕괴선 추격** (PERFECT로 밀어내야 생존) |
| 시간 압박 | 없음 | **있음** — 위험도 HUD·비네트·심장박동 |
| 난이도 | 기준 | 이동속도·판정폭·방해물 밀도 전반 상향 |
| 연출 | 달이 커지며 접근 | 균열 포탈 + **해저 화산**(레벨5+) |
| 죽음 원인 표시 | 통일("TOWER DOWN") | **3종 구분**(맞음/무너짐/삼켜짐) |
